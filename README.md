# Advanced React E-Commerce App

## About

Hello! My name is Jazmin Robinson, and this is my Advanced React E-Commerce project. This application allows users to browse products, filter by category, and manage a shopping cart in a simple and interactive shopping experience.

## Features

- Browse products with images, names, descriptions, and prices.
- Filter products by category.
- Add products to the shopping cart.
- View the total number of items in the cart.
- Update cart quantities.
- Remove items from the cart.
- Clear the shopping cart during checkout.
- Display product ratings and pricing information.

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- Vite
- CSS
- Fake Store API

## Project Highlights

This project demonstrates:

- React component development.
- State management with Redux Toolkit.
- Dynamic rendering of product data.
- Shopping cart functionality.
- Category filtering.
- Responsive user interface design.

## How to Run the Project

1. Clone the repository.
2. Install dependencies:

```
npm install
```

3. Start the development server:

```
npm run dev
```

4. Open the local host URL provided in your terminal.
